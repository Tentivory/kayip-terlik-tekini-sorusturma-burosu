# Kayıp Terlik Tekini Soruşturma Bürosu

> Bir çift terliğin tekini kaybetmek bireysel ihmalken, resmi evrakla kaybetmek ulusal bir meseledir.

Bu yazılım, evin içinde kaybolan **tek terliği** bilimsel olmayan ama evrak düzeni çok yerinde bir soruşturmaya tabi tutar. Şüpheli listesi üretir. Geçici karar verir. Mühür basar.

Patates yoktur. Asansör yoktur. Çay yoktur. Sadece terlik ve ciddiyet vardır.

## Neden bu kadar resmi?

Çünkü çıplak ayakla holde yürümek, hukuken tanımlanmamış bir gri alandır. Bu gri alan doldurulmadan evrenin ısı dengesi bozulur. Büromuz bu dengeyi evrakla sağlar.

## Kurulum

```bash
git clone https://github.com/Tentivory/kayip-terlik-tekini-sorusturma-burosu.git
cd kayip-terlik-tekini-sorusturma-burosu
python3 sorusturma.py --oda salon --son_gorulme "dün gece dizinin ortasında" --sahip "ben"
```

Python 3 yeter. Bağımlılık yoktur. Terlik de yoktur. İşte sorun budur.

## Örnek çıktı

Program çalıştığında şunu benzeri bir resmi evrak basar:

- Evrak numarası
- Olay yeri
- Üç şüpheli (koltuk, kedi, zaman)
- Geçici karar
- Mühür ve imza

## Sık sorulan sorular

**Terliği bulursam ne olur?**  
Belge geçersiz olur. Duygusal olarak geçerli kalır.

**Kediyi suçlamak adil mi?**  
Hayır. Ama kuyruk sallamak da bir ifadedir.

**Bu siyasi bir proje mi?**  
Hayır. Bu bir terlik projesidir. Siyaset holde çorapsız yürümez.

## Lisans

Kamu malı gibi durur, evrak gibi davranır. Kopyalayabilirsiniz. Terliği kopyalayamazsınız çünkü o zaten kayıp.
